# БИОЛИНКС

Интерактивная схема лица и шеи для косметологов.

**Прототип:** https://carstyling-ru.github.io/biolynx/

## Возможности

- Три проекции: анфас, ¾ и профиль.
- Выбор 26 зон и 4 мышц с полупрозрачной цветной разметкой.
- Изменение контуров перетаскиванием вершин и изменение цветов.
- Сохранение в браузере, импорт и экспорт JSON.
- Экспорт одного альбомного листа PDF с выбранными структурами.

Контуры являются стартовой схематической разметкой и требуют уточнения специалистом.

## Разработка

Проект работает без сборки и внешних сервисов. Для локального просмотра:

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173/.

- `index.html` — интерфейс.
- `style.css` — стили.
- `data.js` — исходные анатомические контуры и цвета.
- `app.js` — выбор, редактор и сохранение.
- `pdf-export.js` — формирование PDF в браузере.
- `assets/` — изображения и логотип.
- `vendor/` — pdf-lib и её лицензия.

Правки сохраняются в localStorage браузера и не записываются в репозиторий. Для переноса разметки используйте JSON. Сохранённые данные прежнего домена автоматически не переносятся — экспортируйте их там и импортируйте на этом сайте.

GitHub Pages публикует корень ветки `main`. После обновления файлов и push сайт обновляется автоматически.

## Разметка по умолчанию

В `data.js` опубликованы проверенные цвета и контуры из JSON, перенесённого со старого адреса 11 ноября 2026 года. Эта версия загружается при первом посещении. Разметка, которую пользователь уже сохранил в своём браузере, имеет приоритет перед исходной версией.
